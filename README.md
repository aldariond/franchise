# Franchise HQ Step 11C
Use the existing Supabase project and the fhq_* functions installed in Steps 4–11A. Do not run the old schema.sql. Upload these source files to a GitHub repository and connect it to Netlify. Set VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY in Netlify build environment variables. Build command npm run build; publish directory dist. Set Supabase Authentication URL Configuration Site URL to your deployed HTTPS URL and add it to redirect URLs. Test with separate administrator, approved commissioner, owner and outsider accounts before inviting real users.
This is a test frontend, not production-ready. No live database test or dependency build performed. Manual matchup entry; no Madden JSON import yet. Awards and records are read-only. Rankings use finalized games and a simple win-rate plus margin formula. Picks are not hidden before deadline at the database level. Existing schema constraints/defaults may require adjustments; report errors. No automatic schedule, team assignment, or admin score correction. Do not use secret/service-role keys. Virtual points only.
